# Every fortune source and its current category

Generated from `packs/collections.json`, `catalog.json`, `packs/pack-names.json` and the built-in
corpus `src/Fortunes/fortunes.txt`. 159 sources across 12 collections.

**Origin** is where the text lives: a downloadable **pack**, the **built-in** corpus compiled into
the Fortunes DLL, or **both** (a pack that also has a slice bundled). Only `built-in` and `both`
sources exist before the user downloads anything, so those are the only candidates for what ships
enabled by default.

Categories are sorted by size, sources within each category likewise.
