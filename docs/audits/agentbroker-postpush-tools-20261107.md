# AgentBroker post-push MCP and recovery surface review

Review date: 2026-11-07. Published baseline: `7ab40743b5b40f525921601ac0bc59da56dd73b8`. This independent pass read the stable integration tree's inbox, recovery, declarations, titles, MCP caller and their call chains. The named feature/store/transport files had no integration diff from that baseline at the end of review. No source mutation, build, network call, installed-app action or new test execution occurred.

Review questions: exact-incarnation authority and local-only metadata, atomic snapshot/notification behavior, bounded retention, error propagation and owned-client/task disposal. Confirmed issues require a reachable counterexample. Existing routing and local authorization policy remain settled.

Abbreviated source filenames refer to `tools/AgentBroker.Worker/`; `BrokerStore.cs`, `PendingInbox.cs` and `NativeRecovery.cs` refer to `src/AgentBroker.Core/`. Line numbers identify the reviewed baseline.
