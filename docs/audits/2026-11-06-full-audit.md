# Full code audit, 2026-11-06

Target: master `e20decd` (v1.11.0 and Companion Studio 1.4.0). Read-only: nothing was built, run or edited during
the reading or the verification. A whole guard mutation suite ran separately on the same commit.

## Method

- 33 reader slices covering every tracked code file (balanced by line count) and every Markdown document, each with
  a written brief: evidence at file:line, a concrete counterexample, no style findings.
- 22 gap-fill readers for the files and line ranges the first pass did not reach.
- Consolidation by file, line proximity and title overlap; every finding's slice label was checked against its file.
- Every medium-or-higher finding re-traced by an adversarial verifier told to refute it; severities recalibrated.
- A fixed one-in-eight sample of the low and info findings re-traced the same way.

## Result

- Open backlog entries filed: 397 (medium 56, low 318, info 23), 101 of them verified.
- Findings that repeat an existing backlog item are cross-referenced in BACKLOG.md, not re-filed: 12.
- Refuted findings are not filed.
- Resolved by the commit that filed this audit: A0003 (resolved in the filing commit: N-shimeji-convert-06 re-scoped to the open oracle comparison).
- Spot-check of 40 unverified low and info findings: 39 confirmed, 1 refuted, 0 uncertain, so the unverified entries are expected to be mostly real.
