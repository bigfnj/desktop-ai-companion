# Redistribution rights

The former per-asset rights-evidence gate (source-rights and per-pack approval manifests, bound by
hash and enforced at release time) was retired along with the enterprise release pipeline.

The engine, artwork, fortune corpus, embedder model, and downloadable packs are fan-compiled from
mixed community and upstream sources. Their provenance and attribution are documented in
[`../../THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md),
[`../../packs/README.md`](../../packs/README.md), and
[`../../FORTUNE-SOURCES-ASSESSMENT.md`](../../FORTUNE-SOURCES-ASSESSMENT.md).

That documentation is attribution and disclosure — **not** a blanket redistribution clearance.
Review the sources before redistributing.
