dwebp.exe -- bundled WebP decoder
=================================

This directory contains dwebp.exe, the reference WebP decoder from Google's
libwebp project. ShimejiConvert uses it to decode an Android-Shimeji bundle's
.webp sprites WITH their alpha channel: the Windows Imaging Component (WIC)
codec on some machines decodes WebP as opaque BGR32 and silently drops alpha,
which turned a converted pet's transparent background into an opaque black box.
dwebp is the reference implementation and preserves alpha exactly.

Provenance
----------
Source:   https://storage.googleapis.com/downloads.webmproject.org/releases/webp/libwebp-1.4.0-windows-x64.zip
Version:  libwebp 1.4.0 (windows-x64), file bin/dwebp.exe
Archive sha256: 0e77cfd844f9a25ee10c7bc4fef145a0a855e3be61f9ce0e1893c27a604dab81
dwebp.exe sha256: b2284d94400064fc0b54a8960f5cee57ed9bfac3ac794ceee776fdeaf1a52bab

It is statically linked (depends only on Windows system DLLs), so it ships as a
single self-contained executable.
