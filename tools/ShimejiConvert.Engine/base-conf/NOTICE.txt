Shimeji base behaviour configuration (actions.xml, behaviors.xml)
=================================================================

These two files are the default behaviour configuration from Shimeji-EE
(Shimeji English Enhanced), included UNMODIFIED so that a sprites-only Shimeji
skin -- one that ships only shimeN.png images and no conf of its own -- can be
converted without the user supplying the base configuration separately.
