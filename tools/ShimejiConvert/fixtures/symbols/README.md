sourcelink.json is a synthetic Source Link map in the shape a ContinuousIntegrationBuild gives one: its only key is the mapped /_/ root, and its URL carries a commit-shaped path segment. No build reads it. The mutation harness (tests/mutate-selftest-guards.py) names it in the compiler's SourceLink property of either converter project, which puts a Source Link record into that dll directly, so the cli-roundtrip selftest must refuse the dll with CLI_SYMBOLS_SOURCE_LINK in any copy of the repository, git checkout or not (N-bd-w12-review-04). It names it the same way in src/DesktopAICompanion.ModuleKit and src/DesktopAICompanion.Contracts, where CoreTests' "ModuleKit shipped symbols" group must refuse the dll for carrying a Source Link record (N-bd-w13-review-02).
